# Python Projects

A collection of small Python programs I wrote while learning programming.

## Programs
| File | Description |
|------|-------------|
| `guessing_game.py` | Number guessing game. Guess a number from 1 to 100 in 7 tries. |

## How to run
1. Install Python from python.org.
2. Download or clone this repository.
3. Open a terminal in the folder and run:
   ```
   py guessing_game.py
   ```
